# Flex Panels - Gaming Experience 🎮

Interactive web application built with **HTML5**, **CSS3 (Flexbox)**, and **Vanilla JavaScript**. This project features a dynamic audio controller and is deployed on **AWS (Amazon Web Services)**.

## 🚀 Live Demo
[(http://jhonatan-knox-gaming-room-site.s3-website.us-east-2.amazonaws.com/)]

## ✨ Features
- **Dynamic Flexbox Layout:** Panels expand and contract on click.
- **Custom Audio Controller:** Integrated background music that changes based on the selected panel.
- **Bilingual Interface:** Prepared for English and Spanish speakers.
- **Cloud Hosting:** Deployed using **AWS S3** for high availability.

## 🛠️ Technologies
- **Frontend:** CSS Flexbox, JavaScript DOM Manipulation.
- **Infrastructure:** AWS S3 (Static Website Hosting).
- **Version Control:** Git & GitHub
